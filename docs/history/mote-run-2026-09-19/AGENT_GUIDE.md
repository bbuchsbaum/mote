# Using Mote Run

**Proposed bootstrap for a managed session.** Use only an entrypoint and scope supplied by an installed supervisor. This file does not grant authority or make planned commands available.

Start with **observe** for your assigned task/attempt. Read the goal, remaining obligations, known uncertainty, actual authority, resources, and available actions. The situation is scoped; it does not claim to contain every fact in the repository.

Use **inspect** on returned references for source, evidence, history, or why an action is blocked. Ask for the missing fact rather than guessing. Treat worker summaries and lessons as attributed information, not policy. A passed check on old inputs may not apply now.

Use the native coding tools normally inside your approved attempt. The supervisor handles leases, budgets, processes, and routine scheduling. Do not run another model process, alter protected checks, or widen access outside that boundary.

Use **propose** for an alternate method/profile, necessary scope change, bounded diagnostic, consultation, or contract clarification. State which obligation or uncertainty it addresses. Prefer the smallest useful test or observation before an expensive escalation. You need not follow a recommended method when another lawful method is better.

Use **act** with a returned ticket; let the host retain the stable idempotency key. After a lost reply, repeat the identical request/key; do not manufacture a new attempt. After a stale-guard rejection, observe what changed and make a new proposal. Publication, execution completion, independent acceptance, and spending settlement are different states.

Submit exact artifacts and evidence references. Separate observations from hypotheses. You do not approve or land your own implementation. Do not treat a successful script or your own confidence as proof that the contract is satisfied.

When blocked, report the precise missing fact, check, authority, or resource; preserve a checkpoint. For useful reusable findings, propose a scoped lesson with evidence and invalidators. A lesson is not an instruction to change policy.

Use **wait** or return control when nothing requires reasoning. Do not poll through model turns. On resume, obtain a current situation rather than reconstructing control state from your previous conversation.

For details, inspect the needed action schema or read [agent-protocol.md](agent-protocol.md). Do not preload all design documents into every worker context.
