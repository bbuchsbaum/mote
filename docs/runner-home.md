# One runner home

Runner implementation belongs to **teamd**, with `teamd/PLAN.md` as the canonical
roadmap and teamd Mote issues as the executable work queue. In sibling local
checkouts that file is `../../teamd/PLAN.md` from this directory.

Mote retains authoritative objectives/tickets/graph, claims/reservations, candidate
and review records, evidence references and acceptance. Shared work here concerns
native guarded application services, projections, stable receipts, and event
contracts. Fray routes attention; teamd owns admission, process/attempt lifecycle,
continuation, recovery and persistent resource accounting.

The [JSON catalog](plan.json) preserves MR IDs, requirement coverage and historical
dependencies, marked delegated throughout. It is not another implementation
sequence. The [original source bundle](history/mote-run-2026-09-19/manifest.json)
preserves exact pre-transfer bytes, including the original JSON and generated
roadmap. Current architecture/protocol/PRD retain useful invariants with explicit
ownership. No model activation, publication or candidate acceptance is implied.
